# 新港市 危機管理センター

ブラウザだけで動く、架空都市の危機管理シミュレーターです。第1週目の土台として、都市グリッド、重要施設、ゲーム内時間の開始・停止・速度変更を実装しています。

## 遊び方

- `開始` でゲーム内時間を進めます。
- `1× / 2× / 4×` で時間の進行速度を切り替えられます。
- 地図上の光る施設をクリックすると、施設の状態と座標を確認できます。

## 現在の実装範囲

- 12×8の都市グリッドと道路・海岸の描画
- 病院、変電所、浄水場、消防署、物流拠点の表示
- ライブのゲーム内時計と状況ログ
- GitHub Pagesへの自動デプロイ設定

次の段階では、台風による浸水と停電、避難所・部隊派遣のプレイヤー操作を追加します。
