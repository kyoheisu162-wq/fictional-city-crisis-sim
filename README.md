# 新港市 危機管理センター

ブラウザだけで動く、架空都市の危機管理シミュレーターです。台風による浸水・停電・道路寸断・デマ拡散が連鎖するなかで、市長／災害対策本部として判断します。

公開ページ: <https://kyoheisu162-wq.github.io/fictional-city-crisis-sim/>

## 実装済み

- 台風・浸水・停電の連鎖イベントと、住民安全／インフラ／予算／市民信頼の算出
- 避難勧告、避難所開設、救助隊派遣、緊急復旧班の対策コマンド
- 道路通行率による救助・物流の到達状態と、電力・水道・医療の施設依存関係
- 検証型／即時／沈黙の情報発信方針とデマ拡散
- 状況ログ、終了レポート、ブラウザ内セーブ／ロード
- JSONシナリオエディタ

## 操作

開始後、時間速度を選択し、台風接近から浸水・停電へ連鎖する状況に対処します。地図上の施設をクリックして依存関係を確認し、コマンドと復旧優先度、公式発表方針を使い分けてください。

JSON形式は [docs/scenario-format.md](docs/scenario-format.md) を参照してください。
