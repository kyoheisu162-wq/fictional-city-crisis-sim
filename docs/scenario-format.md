# シナリオJSON仕様

「JSONエディタ」に次の形式を貼り付けると、災害条件を変更できます。

```json
{
  "name": "台風「白波」強化版",
  "start": 360,
  "rain": 480,
  "flood": 600,
  "peak": 0.92,
  "budget": 680,
  "duration": 72
}
```

- `start`: 開始時刻（分。午前6時は360）
- `rain`: 降雨開始時刻（分）
- `flood`: 浸水開始時刻（分）
- `peak`: 台風・浸水の最大強度（0〜1）
- `budget`: 対策に使える予算ポイント
- `duration`: 想定訓練時間（ゲーム内時間）

施設は都市モデルに固定配置されています。電力低下は水道・医療・物流へ、道路寸断は消防・物流へ連鎖します。
